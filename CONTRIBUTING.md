# Contributing to limn

## Licence of contributions

limn is licensed under the GNU General Public License, version 2 or (at your option) any later version: GPL (>= 2). The text of version 2 is in `LICENSE.md`. Contributions come in under the same licence, and no contributor licence agreement is asked for.

Each commit in a pull request carries a Developer Certificate of Origin sign-off: a line

```
Signed-off-by: Your Name <your.email@example.com>
```

which `git commit -s` adds. It certifies that you wrote the change, or otherwise have the right to submit it under GPL (>= 2), as set out at <https://developercertificate.org/>.
